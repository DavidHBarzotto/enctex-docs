# Report

The fourth tab. It issues the pile cap's **calculation report**, in an editable
format.

## Contents { #conteudo }

The report brings together what was calculated:

- Geometry of the pile cap, the piles and the columns
- Actions entered and the **combinations** built
- Load distribution and pile reactions
- Model adopted — behaviour, method, KR factor
- Stress analysis and limits in the struts and nodes
- Reinforcement, with the bar schedule
- Checks — punching, shear, nodes
- Finite element model results, when solved

## What to record beyond the automatic content { #o-que-registrar-alem-do-automatico }

The document is complete as regards what the program calculated. It is worth
completing it with what the program has no way of knowing:

- **Why the cap was classified as rigid or flexible**, when it is on the
  boundary.
- **Why Blévot or MBT**, when the two diverged.
- **The extrapolation of Blévot above four piles**, when applicable — the
  program issues the note, and it should be in the report.
- **The origin of the pile reactions**, whether they came from the SP line or
  were entered by hand.
- **Special conditions** — partially buried cap, construction joint,
  interferences.

!!! warning "The report backs the signature"

    The document records the calculation performed. It does not replace
    engineering judgement nor transfer responsibility — the project is signed
    by the engineer of record.

    The [formulation documentation](../formulacoes/index.md) exists so that
    this signature is an informed one.

## Output { #saida }

The report is **editable**, on purpose: the designer completes the
assumptions before issuing it.
