# Informe

Cuarta pestaña. Emite la **memoria de cálculo** del encepado, editable.

## Contenido { #conteudo }

El informe reúne lo que se calculó:

- Geometría del encepado, de los pilotes y de los pilares
- Acciones cargadas y **combinaciones** armadas
- Distribución de esfuerzos y reacciones en los pilotes
- Modelo adoptado — comportamiento, método, factor KR
- Análisis de tensiones y límites en las bielas y en los nudos
- Armaduras, con la planilla de armaduras
- Verificaciones — punzonamiento, cortante, nudos
- Resultados del modelo de elementos finitos, cuando se resolvió

## Qué registrar además de lo automático { #o-que-registrar-alem-do-automatico }

El documento sale completo en lo que calculó el programa. Conviene
complementarlo con lo que el programa no tiene cómo saber:

- **Por qué el encepado se clasificó como rígido o flexible**, cuando esté en
  el límite.
- **Por qué Blévot o MBT**, cuando los dos divergieron.
- **La extrapolación de Blévot por encima de cuatro pilotes**, cuando
  corresponda — el programa emite la nota, y debe constar en la memoria.
- **El origen de las reacciones de los pilotes**, si vinieron de la línea SP o
  se cargaron a mano.
- **Condiciones especiales** — encepado parcialmente enterrado, junta de
  hormigonado, interferencias.

!!! warning "La memoria respalda la firma"

    El documento registra el cálculo realizado. No sustituye el criterio de
    ingeniería ni transfiere responsabilidad — el proyecto lo firma el
    responsable técnico.

    La [documentación de formulaciones](../formulacoes/index.md) existe para
    que esa firma sea informada.

## Salida { #saida }

El informe es **editable**, a propósito: el proyectista complementa las
hipótesis antes de emitirlo.
